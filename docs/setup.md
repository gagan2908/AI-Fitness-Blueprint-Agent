# ⚙️ Setup Guide - AI Fitness Blueprint Agent

AI Fitness Blueprint Agent is an AI-powered automation project that generates personalized fitness plans using Generative AI and n8n workflow automation.

- Git
- Node.js
- n8n
- Python 3.x
