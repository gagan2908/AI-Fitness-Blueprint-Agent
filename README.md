# 🤖 AI Fitness Blueprint Agent

An AI-powered fitness assistant that generates personalized fitness blueprints using Generative AI and n8n workflow automation.

## 🚀 Overview

The AI Fitness Blueprint Agent takes user health and lifestyle information and generates a structured fitness plan including:

- BMI analysis
- Target weight recommendations
- BMR & TDEE calculation
- Daily calorie requirements
- Macronutrient breakdown
- Workout planning
- Vegetarian meal recommendations
- Hydration and sleep guidance

The complete workflow is automated using **n8n**, allowing AI-generated reports to be delivered automatically through email.
